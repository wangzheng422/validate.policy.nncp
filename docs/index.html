Install with Helm

helm repo add network-guardrail https://wangzheng422.github.io/validate.policy.nncp/
helm repo update
helm upgrade --install network-guardrail network-guardrail/network-guardrail \
  --version 0.2.1 -n network-guardrail --create-namespace

Requires administrator permissions, NMState and served ValidatingAdmissionPolicy APIs. Public images support linux/amd64. Enforcement and host audit collection start disabled.

OpenShift Helm catalog

Register the HelmChartRepository manifest, then find Network Guardrail in the Console catalog.

This demonstration project is not an OpenShift-supported product. Review its security and operational limits before enabling interception.
